BIRTHDAY REMINDER FIREBASE FREE v2.0 — CONFIGURED PACKAGE

Firebase configuration is already inserted in index.html.

UPLOAD TO GITHUB
----------------
1. Open the Birthday-Reminder-Web-App repository.
2. Delete the old frontend files from the repository root.
3. Upload every file from this package directly to the repository root.
4. Commit the changes.
5. Keep GitHub Pages configured as:
   Branch: main
   Folder: / (root)
6. Wait for deployment.
7. Open:
   https://parmjee2026.github.io/Birthday-Reminder-Web-App/?v=2.0-configured
8. Press Ctrl + Shift + R.

FIRST LOGIN TEST
----------------
1. Click Continue with Google & Sync Contacts.
2. Choose a Gmail account listed under OAuth Test Users.
3. Approve read-only Google Contacts access.
4. The dashboard should open.
5. Contacts with saved birthdays should be imported.

IMPORTANT
---------
- Firebase Spark plan remains free.
- No billing account is required.
- No Apps Script URL or private API key is used.
- Each user's data is stored under their own Firebase UID.
- Contacts without a saved birthday cannot be imported as birthdays.
